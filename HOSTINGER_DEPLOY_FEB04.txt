🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════

Problem: Blank page or loading forever
Fix: 
   1. Check browser console (F12)
   2. Clear browser cache (Ctrl+Shift+Delete)
   3. Verify .htaccess exists
   4. Check file permissions (755 for folders, 644 for files)

Problem: 404 errors on page navigation
Fix:
   1. Enable "Show Hidden Files"
   2. Verify .htaccess is in public_html root
   3. Check .htaccess contains RewriteBase /
   4. Contact Hostinger support to verify mod_rewrite is enabled

Problem: Images not loading
Fix:
   1. Check assets/Images/ folder exists
   2. Verify images are inside (BiAN AWARD.jpg, etc.)
   3. Check file permissions
   4. Clear browser cache

Problem: Green color not showing for "Scheduled"
Fix:
   1. Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
   2. Clear browser cache completely
   3. Try incognito/private window
